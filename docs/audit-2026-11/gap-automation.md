## What is already right
- No-false-green chain: `test.fixme` skeletons, `test.fail` kept red in the RTM.
- Locator priority, web-first assertions, `page.clock`, API-seeded state match Playwright 1.65.
- WCAG data: 55 A/AA criteria (31 + 24), automated-plus-manual split, WCAG 3 not tested.
- ASVS 5.0 chapter names V1-V17 and the Top 10:2025 mapping.
- API state budgeting, root-cause grouping, the `Bearer`-less header test, authorisation rules of engagement.

## Not worth doing
- gTAA layers or CT-TAS strategy prose: no change to output.
- JMeter/Gatling generators: one correct k6 generator is worth more.
- A Pact scaffold: needs both teams; the rule and diff script suffice.
- SUS or usability-lab protocols: an agent cannot run them.
- Reproducing ASVS/MASTG text: copyright and upkeep; IDs suffice.
